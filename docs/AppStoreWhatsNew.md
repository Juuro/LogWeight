# App Store "What's New" (release notes)

Per-release text for the store field "What's New in This Version". **Rewrite this file for every release** and set the version below: `Tools/asc-release.py texts` refuses to sync when the version here does not match the target version, so an old text can never ship with a new release.

Format: one `## <locale>` section per language, plain text until the next heading. `en` is used for en-AU, en-CA, en-GB and en-US; `es-MX`, `fr-CA` and `pt-PT` reuse `es-ES`, `fr-FR` and `pt-BR`. Limit: 4000 characters.

**Version:** 1.1.0

## en

Now optimized for iPhone Duo and landscape.

• History shows the chart and the list side by side when there is room, with a wider chart.
• Landscape support on iPhone: entry and history adapt to the wider screen.
• The Save button stays fully visible above the keyboard, also in landscape.

• Die Taste „Speichern“ bleibt über der Tastatur immer vollständig sichtbar, auch im Querformat.
